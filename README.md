# 照片色卡

「照片色卡」是一个面向小红书的照片配色工具。它把一张照片里的颜色提取为可编辑的色块，并将配色、照片和可选标题排成一张图片。它适合记录旅行照片中的配色、整理穿搭配色参考，或为家居软装保存空间色卡。

本文只描述「照片色卡」。当前可上传的程序包是仓库根目录的 [photo-palette-xiaohongshu.zip](photo-palette-xiaohongshu.zip)，其最新内容来自提交 `43dabdc`。

## 用户怎么使用

打开页面会先显示「海边日落」示例，用户可以直接体验。想处理自己的照片时，点击「选择照片」，由系统提供拍照或从相册选择。页面会自动提取配色并更新预览。用户可继续调整色块、版式和标题，最后点击「保存色卡」，或在小红书内直接点击「发笔记」进入发布流程。

## 完整功能

| 功能 | 当前行为 |
| --- | --- |
| 默认示例与恢复 | 初次打开时自动加载内置的「海边日落」照片和示例标题。导入自己的照片后可点「恢复示例」。 |
| 拍照与相册导入 | 点击一次「选择照片」直接打开系统照片选择界面。拍照和相册选项由设备或宿主提供。桌面还支持把照片拖入色卡预览区。每次处理一张照片。 |
| 文件校验 | 文件输入限定图片，单张上限 30 MB。解码能力取决于浏览器或小红书宿主。文件无效、超过大小限制、无法解码或没有可提取的内容时，页面会显示提示。 |
| 自动提色 | 新照片读入后从其像素提取代表色，默认选择 5 色，可选 3–7 色。图像有效颜色很少时，实际可用色数可能更少，页面会展示提示。 |
| 重新提色 | 点击「重新提色」按当前照片和色数恢复自动配色。切换色数也会重新从自动提取结果中选色，覆盖手动调整的色块。 |
| 手动替换颜色 | 点击任意色块打开原图取色弹框，点选原图像素或输入六位 HEX 色号，再点「替换颜色」。支持键盘方向键移动取色点，透明区域会提示重新选择。 |
| 相纸版式 | 默认版式。以留白边框展示照片，配色和可选标题排在照片下方。 |
| 满幅版式 | 照片铺满卡片宽度，色块紧接在照片下方。照片为适配版式可能裁切。 |
| 纯色卡版式 | 用大色块展示配色，可配标题和色号，适合只分享配色。 |
| 卡片标题 | 可选，输入框最多 20 字。导入自己的照片时清空示例标题。 |
| 显示色号 | 默认开启。可切换是否在生成的色卡图片里显示 HEX 色号，编辑面板仍显示色号。 |
| 即时预览 | 修改颜色、色数、版式、标题或色号开关会重绘 Canvas，页面也显示当前图片来源和色卡像素尺寸。 |
| 保存色卡 | 小红书内调用宿主接口保存生成的 PNG 到相册。普通浏览器显示可长按或右键保存的大图。 |
| 发笔记 | 小红书内点「发笔记」会把生成的色卡图及预填标题、正文和话题交给小红书发布页，用户在发布页确认发布。普通浏览器会提示在小红书内打开。 |
| 移动端操作栏 | 在 680 像素及以下的视口，选择照片、保存色卡和发笔记集中在底部。更宽的布局把选图放在页首，保存和发笔记放在编辑区下方。 |

## 实现与数据边界

- 原生 HTML、CSS、JavaScript 和 Canvas。照片加载、缩放、提色、手动取色和渲染都在当前设备完成，无应用后端和账户系统。编辑状态保存在当前页面内存中，刷新后重新显示示例。用户主动选择发笔记时，生成的色卡图交给小红书发布流程。
- 处理照片时最长边缩放至最多 1500 像素。提色先采样并统计像素，然后在 Lab 色彩空间聚类并比较颜色差异。色卡基础宽度为 960 像素，高度随版式与内容变化。导出体积较大时，程序会尝试缩小 PNG 后再交给保存或发布接口。
- 小红书宿主接口通过 `window.xhs.miniTool` 访问。保存接口为 `saveImageToPhotosAlbum`，发笔记接口为 `postNote`。系统相机、相册权限弹窗和发笔记发布页由宿主管理，真机行为须在小红书内验证。

## 代码与预览

仓库以 ZIP 保存完整网页。解压后，`index.html` 在包的根目录，项目使用原生 HTML、CSS、JavaScript 和 Canvas，无需安装项目依赖或执行构建。

| ZIP 内路径 | 用途 |
| --- | --- |
| `index.html` | 页面入口，含色卡预览、编辑面板、照片输入和弹框。 |
| `assets/style.css` | 页面样式、响应式布局和移动端底部操作栏。 |
| `assets/main.js` | 选图与图片解码、编辑状态、交互事件、保存及小红书接口。 |
| `assets/palette.js` | 对照片像素采样与聚类，在 Lab 色彩空间比较颜色差异。 |
| `assets/card.js` | Canvas 色卡渲染、版式和导出尺寸。 |
| `assets/example.jpg` | 「海边日落」默认示例，也是封面的图片素材。 |

本地预览可将 ZIP 解压到任意目录，在解压目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。修改网页后，按原有目录结构更新 ZIP，确保 `index.html` 仍位于包根目录，再用 `unzip -t photo-palette-xiaohongshu.zip` 校验。普通浏览器可以验证选图、编辑和预览，小红书真机用于验证系统选图、保存和发笔记。
