# 独立横屏录制布局

这是在当前发布 ZIP 的临时解包副本上运行的横屏演示适配，供宣传片制作使用。原发布 ZIP、原 `dist/`、小红书工程和玩家存档均不修改。该布局未发布到线上，不表示当前线上游戏已经支持横屏。

- 直接由 Phaser 渲染完整 1920×1080 游戏画面，固定摄像机；没有视频裁切、平移、留黑、拉伸、手机框、外部画中画或后期拼接。
- 逻辑视口为 1152×648，通过固定、等比的游戏摄像机渲染到 1920×1080 画布；人物、泡泡和怪怪不作横向拉伸。
- 关卡标题、状态、七列敌阵、瞄准与反弹路径、安全线、角色、炮台、能量和道具按钮均在同一视口内。
- 重新排列横向坐标、HUD、弹窗和输入坐标；背景为游戏渲染器绘制的连续像素场景。实际战场几何随横向布局改变，因此不声称线上竖屏关卡的难度测评可以直接用于此演示布局。
- 敌人生命、伤害、关卡波次、能量、星糖、道具与声音仍由当前游戏模块提供，没有通过设置生命、添加奖励或调用胜利方法伪造操作。
- 操作通过正常鼠标输入完成，包括拖动瞄准、发射、按游戏已有功能长按加速，以及积能后点大泡泡；音乐、音效均实时采集。
- 每次状态变化及飞行时持续检查画布覆盖全部视口、摄像机不变、所有存活敌人／角色／炮台／操作条均没有越出视口。

制作：`python storefront/landscape-demo/record.py`。需要 Python Playwright、Chromium、Playwright 录屏 FFmpeg 和系统 FFmpeg。生成完整 40 秒 MP4、画面预览与 `validation.json`。`record.py` 只向临时目录写入适配脚本和 CSS，随后删除临时副本。

`preview-battle.png` 为完整战斗界面预览，`preview-title.png` 为首页，`preview-victory.png` 为正常通关结算。平台是否给予首页推荐仍由平台复审决定。
