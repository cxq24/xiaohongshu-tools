# 阿噗的糖果弹弹冒险 · 首个可玩章节

## 目标与主题

小龙阿噗吐出一串弹力泡泡，清除糖果森林的果冻怪，救出星星伙伴。人物实际参与蓄力、吐泡泡、胜利与失败反馈。美术采用明亮柔和的像素童话风。

## 回合循环

观察剩余果冻和机关 → 拖动瞄准（预览首次接触前的路线及墙面反弹）→ 松手发射 → 连锁碰撞与能量积累 → 泡泡返回 → 所有敌人前进一排，加入下一波 → 再次瞄准。

- 胜利：所有预定波次已到场，且场上没有果冻敌人。
- 失败：任一果冻的碰撞体下缘到达安全线。
- 爆米花和彩虹糖属于机关，不计入必须清除的敌人。
- 清屏过程允许任意合法反弹路线，玩家不需要按参考解操作。

## 已实现元素

| 元素 | 行为 |
| --- | --- |
| 绿色果冻 / 浆果果冻 | 数字表示剩余耐久，受击闪白、压扁并产生像素碎片 |
| 爆米花桶 | 被击破后对邻近目标造成 4 点伤害，可继续引爆其他桶 |
| 彩虹糖 | 被击中后，当前轮泡泡获得 3 秒穿透，按游戏内时间计算 |
| 阿噗的大泡泡 | 命中果冻积能，100% 后主动选择；下一轮首颗球体变大、伤害为 4，其余球体仍为普通泡泡 |
| 果冻王 | 第六关出现，击破后分裂为两只较弱果冻，清除后才算击败 |
| 加速 / 收球 | 加速为 2 倍；收球放弃剩余碰撞并推进敌人，避免无限等待 |
| 星级与地图 | 按回合数和是否提前收球结算，过关解锁下一关，保留历史最高星级 |

## 六关节奏

1. 糖果林入口：少量低耐久果冻，认识反弹与机关。
2. 软糖溪谷：相邻果冻与爆米花桶，强调连锁。
3. 彩虹小径：较厚目标与穿透糖，学习射入敌群。
4. 爆米花营地：更多波次，能量技能开始发挥作用。
5. 布丁山坡：交错排布，考验威胁优先级；本版没有布丁跳台机关。
6. 大果冻的城堡：宽碰撞体首领、分裂和援军波次。

## 范围

首版所有关卡共用一套糖果森林背景；六关名称不代表六套独立美术场景。已实现主角六帧表情、果冻受击变形、粒子、背景、预览瞄准线、回合状态、进度保存和可选音效。

讨论中提过的布丁跳台、更多可选角色、多章节背景、广告或付费、排行榜、平台账号均未实现。尚未做真人难度、时长或留存测试，不能把自动测试通关当作可玩性结论。

## 0.2.0：用户反馈后的规则与奖励

### 发射次数、到场批次和耐久

- 发射次数记录已经松手发射的次数，初始为 0，每次发射增加 1。
- 批次表示关卡预定的敌人行何时进入棋盘。第 5 关共五批，其中三批开局已到场；批次不是可用发射次数。
- 全部批次到场后，仍需清除余敌。发射七次、八次本身不会失败；敌人越过安全线才失败。
- 单只果冻的数字表示剩余耐久，普通泡泡每次造成 1 点，大泡泡 4 点，爆米花爆炸也能造成伤害，所以没有统一的“命中 N 次”通关条件。
- 清除计数只计算果冻敌人，爆米花和彩虹糖不算；果冻王及其两只分裂体都计入关卡总目标。

### 奖励与用途

| 情况 | 星糖奖励 |
| --- | --- |
| 首次通关一星 / 二星 / 三星 | 35 / 40 / 45 |
| 重复通关 | 5 |
| 超过历史最佳星级 | 每提升一星额外 +5，与本次重玩 5 叠加 |
| 失败、重复触发同一结算 | 0 |

营地可解锁：莓果阿噗 40、海盐阿噗 80、星光泡泡 40、彩虹泡泡 70。薄荷阿噗与普通泡泡免费。已拥有的外观重新装备不扣钱，星糖不足不购买。换色使用新的像素图与相同动画帧，不仅改变按钮状态。所有外观均不增强伤害。

短期目标是过当前关、拿到可立即使用的奖励；中期目标是更高星级、下一款外观以及救齐六颗星星。旧玩家按已获得的星级一次性补发首通奖励，避免升级后丢失成就。

这是首个实际可用的激励循环，不等于已经解决长期留存。六关内容仍然有限；每日挑战、新章节和更多收集内容是下一阶段可验证的方向，本版没有实现，也没有留存提升的数据。

### 声音设计

用户选择的是卡通拟声与字幕。背景音乐、音效和角色声音有独立音量，首次点击启动声音，可静音并保存设置。

- 背景：原创 8 小节像素旋律与低音，循环播放，不随两倍游戏加速改变音高。
- 普通连发：每颗触发短而偏高的气泡音，轻微变调，保留连发节奏。
- 大泡泡：低频、较长的弹出与尾音，与普通泡泡明显区分。
- 果冻受击：柔软挤压音；浆果果冻和首领音高更低。消失、爆米花爆炸和彩虹穿透另有音色。
- 阿噗：出发、技能就绪、获胜、失败各有短促卡通拟声，同时通过提示或结算文字表达台词。
- 通过节流和并发上限控制密集命中的声音数量，并用动态压缩控制叠加峰值。

所有音频由 Web Audio 在本地合成，无外部音源、第三方配音、TTS 或音频文件下载。未把卡通拟声描述为真人中文配音。

## 0.3.0：300 关主题冒险

- 外层世界：10 个岛屿区域，展示迷雾、区域进度和主题机制。进入后是可滚动的弯曲路线、30 个节点、精英与首领标志。
- 每章 30 关；15 与 25 关为精英节点，30 关为首领。前六关保留旧版配置；第六关仍有旧版小首领。
- 主线由冻结的设计规则生成 300 份不同结构。敌人排布、爆炸弱点、空隙、波次、障碍位置和主题机制组合变化；耐久只承担一部分难度。
- 难度为波浪式上升，新主题和机制留有学习空间，不宣称每关都比上一关难。自动瞄准平均发射次数从第一章约 4.2 次到最后一章约 6.0 次，仅作为内部校准指标，不代替真人测试。
- 普通石障碍不可破坏；冰障碍被击中三次后破碎；弹跳台改变方向；挡板横移；镜面改变反射方向；屏障按周期开放；成对传送门保留运动方向并有冷却；水流/风场提供横向加速度。
- 精英与首领没有购买强度要求。全部主线有无道具解，已实际模拟通过。

### 星糖与解锁

首通收入随主题小幅增长，基础奖励为 30 + 星级×5 + 主题序号×5；升星和重玩规则沿用。通章免费解锁下一章，高价提前入口只允许开启相邻主题，不重复收费。价格从 3400 星糖逐章递增到 6400；其作用是备用捷径，默认路线是顺序通关。

皮肤和永久装备只在商店花星糖购买。远眺瞄准镜延长预览，启明星徽章提供开局 15% 能量；都不是通关必需品。主题泡泡需先开启对应区域再购买。旧外观价格和已购买状态保留。

### 道具、任务与彩蛋

普通关每三个首通给一个普通道具。每章的三项任务和连击彩蛋都有一次性标记，奖励不会因刷新或重复结算重发。普通关不掉落稀有消耗品。

缓冲护盾冻结一次推进且不插入新行，避免敌人重叠。时光回退恢复上次发射前的目标、耐久、冰壳、波次、能量、障碍和统计；库存和已消费的道具不回滚。障碍消除移除最靠近安全线的障碍，星爆使下一次首颗泡泡伤害为 6，不能和能量大招重复消耗叠加。

### 自有视频支线

每章三处隐藏入口在本章第 5、15、25 关首通后出现。完整观看用户自己的宣传片后开放，跳过完全不阻挡主线。开放后重复挑战不再要求重新观看，稀有奖励仅首通一次。

尚未收到宣传视频，也没有配置播放 URL，正式界面保持待配置状态。测试素材是开发时生成的 31 秒单色片，仅在临时目录验证播放器，绝不混入交付包。不将此机制描述为平台激励广告收益。

## 0.4.0：战斗操作和独立火力

- 移除手动/自动加速选项和提前收球入口。正常发射不中断，防卡死仅在极端循环时施加回落，不放弃命中或直接结束回合。
- 战斗操作栏为主菜单、道具袋、大泡泡和退出。道具袋为同页收起式六图标栏，选中显示一行用途与使用按钮，成功使用后收起。
- 退出/返回章节必须确认，取消会保留当前场景和在飞泡泡；确认退出不返还已消耗的道具，也不影响已结算奖励。
- 阿噗在发射器旁操作；炮台、泡泡和角色装扮仅改变图片。火力升级使用独立等级，不绑定皮肤属性。
- 进度门槛与星糖共同限制 50 档火力；旧关保持成长后的伤害。预算和生命标定见 BALANCE.md。
- 图鉴读当前关配置，展示敌人生命区间和按当前火力计算的预计命中数；长按场上敌人可查看具体剩余生命。冰壳单独说明。
- 声音设置精简为总开关与三条音量滑杆，音乐在设置时保留播放；技术诊断不进入用户流程。
- 营地按商品作用分类；外部仓库按已拥有的物品分类；任务奖励、星糖余额和消费使用统一像素图标。

隐藏关按关卡配置提供限时、守护、机关和首领规则。守护中敌人越线消耗工程师生命；首领越线扣两颗生命，生命耗尽失败。限时关计入思考和飞行时间，但菜单、道具栏和图鉴暂停计时，时光回退不返还时间。首领挑战仍为单人，不表示真实多人协作。
