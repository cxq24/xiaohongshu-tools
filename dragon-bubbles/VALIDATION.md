# 验证记录

0.1.0 完整战斗验证针对 `dragon-bubbles-0.1.0.zip` 解压后的实际网页，通过本地 HTTP 服务在 Chromium 中执行。测试脚本是 `tools/browser_checks.py --archive`，结果保存在 `tools/last-test-results.json`。

## 真实输入与页面检查

- 标题开始按钮、关卡说明确认按钮能正常操作。
- 鼠标瞄准发射后，真实物理碰撞造成伤害；所有球返回后推进波次。
- 推进后所有静态碰撞体与图像中心对齐，避免缩放/刷新偏移。
- 打开帮助后，泡泡位置和游戏计时保持不变；关闭后恢复。
- 实际移动端触摸事件从阿噗位置开始，拖动瞄准、松手发射并命中敌人。
- 390 像素宽布局无横向溢出。
- 画布关闭图像平滑；引擎版本为 3.90.0。
- 未捕获 JavaScript 页面错误；所有 HTTP 资源来自本地包，图像解码产生的 blob URL 也属于本地来源，无外部运行请求。
- 通过六关后的解锁及星级在页面刷新后保留。

## 机制与回归检查

以下使用隔离测试局面调用实际游戏方法，区别于完整通关；不将这些布置操作冒充用户手动通关。

- 爆米花连锁会损伤邻居，并继续引爆第二个桶。
- 泡泡实际穿过彩虹糖后获得穿透，命中后方果冻仍保持向上运动。
- 满能量后通过按钮选择大泡泡，发射后首颗球伤害为 4，并消耗能量。
- 敌人推进越过安全线触发失败，重试按钮重新开始关卡。
- 第六关果冻王被击破后分裂；重复挑战仍正常分裂，避免首领状态跨局残留。
- 切换页面清除临时粒子，避免重试累积遗留图形。

## 打包与来源检查

- npm 下载的 Phaser 发布包按注册表 integrity 校验完整 SHA-512。
- 本地引擎文件按 `vendor-provenance.json` 校验 SHA-256，保留 MIT 许可证。
- ZIP 仅包含运行所需 HTML、CSS、JS、PNG ；完整许可证保留在 HTML 注释中（0.1.1 修正）；入口为根目录 `index.html`。
- ZIP CRC 与每个包内文件和 `build/` 的字节一致性通过。
- 固定 ZIP 时间戳，同一输入重复打包得到相同 SHA-256。
