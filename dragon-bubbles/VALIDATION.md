# 验证记录

0.1.0 完整战斗验证针对 `dragon-bubbles-0.1.0.zip` 解压后的实际网页，通过本地 HTTP 服务在 Chromium 中执行。测试脚本是 `tools/browser_checks.py --archive`，结果保存在 `tools/last-test-results.json`。

## 真实输入与页面检查

- 标题开始按钮、关卡说明确认按钮能正常操作。
- 鼠标瞄准发射后，真实物理碰撞造成伤害；所有球返回后推进波次。
- 推进后所有静态碰撞体与图像中心对齐，避免缩放/刷新偏移。
- 打开帮助后，泡泡位置和游戏计时保持不变；关闭后恢复。
- 实际移动端触摸事件从阿噗位置开始，拖动瞄准、松手发射并命中敌人。
- 390 像素宽布局无横向溢出。
- 画布关闭图像平滑；引擎版本为 3.90.0。
- 未捕获 JavaScript 页面错误；所有 HTTP 资源来自本地包，图像解码产生的 blob URL 也属于本地来源，无外部运行请求。
- 通过六关后的解锁及星级在页面刷新后保留。

## 机制与回归检查

以下使用隔离测试局面调用实际游戏方法，区别于完整通关；不将这些布置操作冒充用户手动通关。

- 爆米花连锁会损伤邻居，并继续引爆第二个桶。
- 泡泡实际穿过彩虹糖后获得穿透，命中后方果冻仍保持向上运动。
- 满能量后通过按钮选择大泡泡，发射后首颗球伤害为 4，并消耗能量。
- 敌人推进越过安全线触发失败，重试按钮重新开始关卡。
- 第六关果冻王被击破后分裂；重复挑战仍正常分裂，避免首领状态跨局残留。
- 切换页面清除临时粒子，避免重试累积遗留图形。

## 打包与来源检查

- npm 下载的 Phaser 发布包按注册表 integrity 校验完整 SHA-512。
- 本地引擎文件按 `vendor-provenance.json` 校验 SHA-256，保留 MIT 许可证。
- ZIP 仅包含运行所需 HTML、CSS、JS、PNG ；完整许可证保留在 HTML 注释中（0.1.1 修正）；入口为根目录 `index.html`。
- ZIP CRC 与每个包内文件和 `build/` 的字节一致性通过。
- 固定 ZIP 时间戳，同一输入重复打包得到相同 SHA-256。

## 0.3.0：主题世界、仓库与声音恢复

### 数据与模型

- 固定数据含 10 个主题、300 个主线关、30 个隐藏挑战。300 份结构签名互异，签名包含敌人种类与位置、波次、障碍、传送门、风场和冰壳，排除了单纯耐久变化。
- Node 模型检查覆盖全部 300 次顺序解锁、付费只开放相邻区域、余额不足/重复购买、任务不重复发放、仓库不出现负数、旧存档保留、稀有首通奖励仅发一次。
- 首章保留旧六关。存档 schema 升为 3，保留原 localStorage 键。

### 实际物理引擎全量模拟

`simulate_campaign.py` 在 Chromium 中加载真正的 Phaser 游戏，手动推进其 Clock、Arcade World 和游戏更新。仅关闭粒子效果来减少测试开销，未修改敌人耐久、物理碰撞、胜负条件或发射数量，也未使用仓库道具或付费装备。

- 主线 300/300 获胜，隐藏战斗 30/30 获胜，全部消灭计数与目标总数一致。
- 每关采用测试瞄准策略选择角度，保留实际角度和统计。策略会使用游戏内自然获得的大泡泡能量，但不使用库存道具。
- 隐藏战斗模拟从测试入口直接进入，不代表真实视频已接入；视频解锁与奖励另由浏览器集成测试覆盖。
- 章节平均发射次数约为：4.20、4.03、4.60、4.10、4.57、5.10、5.53、5.47、5.10、5.97。不是严格单调，人类的认知难度也不同于自动瞄准策略。
- 证据：`tools/campaign-validation.json` 与三个 `simulation-*.json`，包含每关结果和可复现发射角度。

### 浏览器集成

`campaign_browser_checks.py` 从实际 ZIP 解压运行：

- 世界图有 10 个区域，章内有 30 个节点，未解锁按钮不可进入，付费后只开放下一主题首关。
- 真实 AudioContext 经手动 suspend 后，普通屏幕点击能恢复播放，无需触发音量键。
- 额外泡泡在本次发射增加 3 颗，重复准备不重复扣费；回退恢复发射前状态且不返还稀有道具；护盾冻结推进；障碍消除减少一个障碍。
- 仓库打开时战斗暂停；在其上打开/关闭帮助也保持仓库暂停。
- 无视频配置时不能开启隐藏关，无倒计时替代播放。
- 使用临时生成的 31 秒测试片验证：跳过不解锁，快进不计入完整观看，实际完整播放后才能进入隐藏关；稀有奖励不重复发放。
- 测试视频不在源码运行目录或 ZIP 中，生产配置 URL 为空；没有实际接入用户的宣传片或广告平台。

### 限制

iPhone 小红书预览的真实声音表现尚需用户复测。桌面 Chromium 的挂起/恢复检查验证修复路径，但不能证明宿主的系统音频通道表现完全一致。请求 `audioSession.type=playback` 采用能力检测，不覆盖系统音量。

300 关是规则生成并冻结的数据，不是 300 个逐关手工设计、人工试玩的关卡。全量模拟证明存在已通过的路线；真人手感、跨帧率表现、难度曲线和长期留存仍需实际试玩。宣传片文件及其可用于宿主的 HTTPS 托管地址尚未提供，因此正式隐藏入口保持待配置。

### 限制

全量模拟是推荐火力下的可完成性验证，不代表初始 100 伤害可以完成全部 300 关，也不代表已有人类难度或留存数据。真实 iPhone 小红书环境及音量通道仍需用户复测。本版不含真实多人联机。
