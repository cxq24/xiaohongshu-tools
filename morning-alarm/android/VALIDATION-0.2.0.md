# Android 0.2.0 验证

日期：2026-11-24。构建工具：Java 21、ECJ 3.38.0、Android API 35 / Build Tools 35.0.0。运行环境：Android 15 / API 35 官方 x86_64 模拟器（软件仿真，无 KVM）。

## 通过

- 资源/Java/DEX 编译、APK CRC、zipalign 与 v2/v3 开发签名验证。
- 0.2 与已交付 0.1 的签名证书一致，可覆盖安装；在模拟器中完成升级安装。
- 7 项排程模型检查：即将到点、时间边界、工作日/周末、每周重复、跨年与非法输入。
- 5 项顺序模型检查：默认值、去重与未知键、用户排序、空存储和旧配置迁移。
- Android 原生流程检查：两步初始化、选择方案、首页/顺序/二级设置导航、实际触屏拖拽及持久化、通过可访问菜单上下移动、130% 字体配置生效与主操作尺寸、夜间切换。
- 10 秒真实 AlarmManager 调度 → Receiver → 前台播放服务；短按不关闭，关闭系统动画时仍需要长按 → 停铃并进入播报。
- 原生 MediaPlayer 本地旋律、暂停/继续、跳过、日历未授权继续后续流程、空提醒跳过、结束后前台服务释放。
- 缺少中文语音的明确跳过与完成提示。模拟器此次返回：`天气示例缺少可用中文语音，已跳过`；没有将此结果表述为听到了中文语音。
- 日间/夜间 12 组语义文字配色对比检查：全部 ≥4.5:1；最低一组为日间 secondary/surface，约 4.66:1。这不是对所有系统控件或完整 WCAG 的认证。

最终原生测试返回 `INSTRUMENTATION_CODE: -1`，完整记录见 [last-redesign-result.txt](tests/last-redesign-result.txt)。测试 APK 不包含在用户安装包中。测试脚本只允许在可丢弃的模拟器执行并会重置测试 App 偏好。

界面图通过 Android PixelCopy 从实际应用 Window 截取，避免软件模拟器的整屏合成滞后把上一页误标为当前页。图片见 [0.2.0-previews](../releases/0.2.0-previews/README.md)。不是美术效果图，也没有拼接系统状态。

## 未验证与限制

- 未在用户真实手机验证后台省电、自启动、锁屏全屏弹出、重启恢复、蓝牙/来电与中文听感。
- 未连接真实天气或第三方音乐服务；天气明确标示为固定示例，音乐为随包附带的原创旋律。
- 系统日历已实现按需只读权限和当天读取，但此次运行验证的是“未授权时跳过”，没有声称已验证各品牌日历提供商的实际事件读取。
- 未实测 Android 8–14 的所有版本；最低 API 26 的相关 API 已按版本分支处理，完整执行环境为 API 35。
- 语音续播使用引擎最近朗读范围，从范围起点恢复；引擎未提供范围时从该条开头继续。

模拟器安装、功能状态和本地播放器通过不等于真实手机听感或长期闹钟可靠性通过。先在用户设备测试，再决定是否替代日常起床闹钟。
