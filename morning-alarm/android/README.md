# 早一点 · Android 0.2.1

原生安卓晨间闹钟 Demo，支持 Android 8.0 及以上。设计规范见上一层的 [DESIGN.md](../DESIGN.md)。沿用 0.1 的包名和开发签名，可覆盖安装并保留已有设置。

## 手机上测试

1. 下载 `little-morning-0.2.1.apk`，用安卓文件管理器打开安装。若提示未知来源，只需按系统提示允许当前来源安装，无需开启开发者模式。
2. 首次进入选择起床时间，再选“极速通勤”或“轻柔唤醒”。现有设置会迁移，之后也可以在设置中重新选方案。
3. 首页只保留大时间、重复星期、开关和一行“起床后”播报摘要。点击时间修改，点击摘要编辑播报；右上角只有设置入口。
4. 点“起床后”播报摘要进入顺序页：开关控制项目，长按右侧把手拖拽；点击把手也能上移/下移。点项目名称进入二级设置。
5. 在播报编辑页底部点“试听我的早晨”体验播放器；底部是暂停/继续、下一条和结束。语音续播依赖引擎的朗读范围回调，从最近范围起点恢复；不提供范围回调的引擎会从该条开头继续。
6. 点“设置 → 体验响铃 → 10 秒后体验起床”。先保持前台测试，再安排一次并锁屏测试。响铃页短按不会关闭；长按约 0.8 秒后立即停止铃声，进入播报。关闭系统动画也不会绕过长按时间。TalkBack 用户可以激活标准点击动作。
7. “再睡 5 分钟”不会播报；“设置 → 体验响铃”中可以取消体验/贪睡。系统通知也有起床、稍后提醒或播放控制。
8. 设置中可以选择跟随系统、日间、夜间，调整音量和语速。系统闹钟音量仍会影响实际响度。

## 内容与兜底

- **天气**：仍是标明“示例”的固定天气；城市手动填写，不申请不必要的定位权限，不伪装成实时预报。
- **音乐**：20 秒随包附带的原创合成旋律，支持离线播放；未连接第三方音乐账号或歌单。
- **日程**：默认手动填写、重复使用；可显式选择系统日历，仅请求 `READ_CALENDAR`，读取今天最多 5 项，不新增或修改。真实日历提供商兼容性需在设备上验证。
- **提醒**：手动填写，持续使用直到修改。
- 日程/提醒为空、日历未授权/无事件/读取失败，会记录原因并跳过，继续后续内容。
- 中文语音缺失或初始化超时，会跳过无法朗读的项目，保留本地音乐等可用内容；完成页提供中文语音设置入口。
- App 没有 `INTERNET` 权限。系统语音引擎是否联网取决于手机所选引擎及语音包，不能保证所有引擎离线。

## 手机权限

设置 → 闹钟与权限中分别处理通知、准时响铃、锁屏全屏显示。Android 12+ 的准时响铃在系统“闹钟和提醒”页面允许；Android 14+ 的锁屏全屏通知需要单独授权。未允许全屏时可点通知进入，实际弹出行为由系统决定。

部分品牌手机需要在电池管理中允许后台运行/自启动。静音/勿扰、闹钟音量为零、蓝牙输出、系统强行停止、重启前未首次解锁等情形需要真机验证。不要在完成设备验证前替换日常起床保障。

## 开发

无需外部应用库或 Gradle。使用 Java 21 运行 Eclipse Java Compiler 3.38.0、Android 官方 API 35 与 Build Tools 35.0.0：

```sh
cd morning-alarm/android
python3 bootstrap.py
bash build.sh
```

默认工具和输出在 `/workspace/.android-build-tools`。可用 `MORNING_ANDROID_TOOLS`、`MORNING_ANDROID_OUT` 覆盖。bootstrap 校验 Google 和 Maven 上游 checksum，不关闭 TLS 检查。首次生成本地开发签名密钥；不把私钥提交仓库。后续更新需沿用同一密钥。

排程与顺序模型：`tests/NextAlarmTest.java`、`tests/PlanOrderTest.java`。原生界面与服务：`tests/RedesignInstrumentation.java`。0.2 的完整流程记录作为历史基线保留。本版的入口迁移、极简首页和偏好保留检查使用 `MinimalHomeInstrumentation.java`，仅在可丢弃的模拟器运行并写入测试偏好：

```sh
python3 tests/run-minimal-home-tests.py
```

该脚本假设模拟器已启动且完成 boot，已安装旧版作为覆盖安装基线，并且当前 APK 已构建。它会安装 App 和独立测试 APK、授予模拟器测试权限并执行流程，检查真实控件并保存设备截图。测试代码不会被打入用户 APK。验证范围见 [VALIDATION.md](VALIDATION.md)。
