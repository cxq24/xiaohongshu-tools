# Android 0.2.1 验证

日期：2026-11-24。此次只收简首页并迁移入口；闹钟接收、播放服务、排序、配色与播报内容逻辑沿用 0.2.0。

## 本版已执行

- Java / AAPT2 / D8 构建、签名校验；证书与 0.2.0 一致。
- 在已有安装中写入时间和提醒偏好，覆盖安装后验证仍保留。
- Android 15 原生检查通过：首页没有试听大按钮、体验入口、额外标题或底部说明；摘要为单行，完整内容保留在可访问描述。
- 点击大时间实际编辑并保存；开关能安排及取消真实 AlarmManager 闹钟。
- 点摘要进入播报编辑页，试听能打开并实际播放本地音乐；结束后回到编辑页。
- 设置 → 体验响铃能安排 10 秒测试；取消体验/贪睡入口能够取消临时排程。
- 日间、夜间及 130% 字体下检查首页，并保存实际应用窗口截图。

最终结果 `INSTRUMENTATION_CODE: -1`，见 [last-minimal-home-result.txt](tests/last-minimal-home-result.txt)。运行入口为 `tests/run-minimal-home-tests.py`，仅允许在可丢弃的模拟器执行，会写入测试偏好。

[查看 0.2.1 界面图](../releases/0.2.1-previews/README.md)。截图为 Android PixelCopy 的实际应用 Window，不是美术效果图，不含系统状态栏或导航栏。
