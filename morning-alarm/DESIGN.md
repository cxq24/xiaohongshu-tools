# 早一点 · Android 0.2 设计规范

2026-11-24。先固定本规范，再实现各页。

## 产品与使用场景

用户睡前设置一次，早晨在低注意力状态下结束闹铃，随后按固定顺序听播报。成功标准是无需每天配置，半醒时不会误结束、不会在首页寻找关键动作。

0.1 的问题：权限按钮与设置表单挤在首页；时间、说明、控制都使用近似权重；原生默认控件没有共同的尺寸和色彩规范；响铃与播放器没有各自的操作模型。0.2 围绕信息层级和状态转换重做，不以装饰弥补流程问题。

普通文字目标对比度至少 4.5:1，主要文字不依赖降低透明度。默认跟随系统，设置中可选日间/夜间。响铃时不突然切到白色页面。无发光、玻璃拟态、大面积渐变或无意义循环动画。

- 字体：Android 系统 sans-serif；时间使用 sans-serif-light 与等宽数字。时钟 104sp（窄屏自动适配 64–104sp），页面标题 28sp，次标题 20sp，正文 16sp，说明 14sp，辅助 12sp。
- 间距：4/8/12/16/24/32/48dp。页面左右 24dp；短屏或大字体可滚动，固定操作区不覆盖内容。
- 热区：所有可操作元素至少 48×48dp；主按钮至少 56dp，响铃结束动作至少 80dp。图标视觉尺寸不等于热区尺寸。
- 圆角：主按钮 16dp，提示面 12dp；首页不使用时钟卡片和卡片嵌套。列表主要靠留白及细线组织。
- 动效：状态切换最多 180ms 淡入，遵循系统关闭动画设置。长按进度仅用于解释触发状态。

## 页面与动作

### 首次进入（仅首次，旧配置迁移后保留）

两步：① 选择起床时间；② 选择“极速通勤”或“轻柔唤醒”。每页只有一个主动作。方案说明直接展示顺序与大致时长。完成后进入首页，不自动申请所有权限或悄悄启用闹钟。设置中可以重新选择方案。

- 极速通勤：天气示例 → 手动日程，短播报。
- 轻柔唤醒：20 秒本地原创旋律 → 天气示例 → 提醒。
- 用户随后可在独立顺序页启停项目、长按拖拽排序；同时提供上下移动作为无障碍替代。

### 首页

上半屏只有“下一次起床”、大时间、重复日与开关；时间整体可点进时间子页。下半屏展示“晨间播报”及一行/可换行顺序摘要，点击进入编辑。唯一主按钮“试听我的早晨”。设置入口与“体验”入口在导航区，权限缺失只出现一条带行动的就绪提示，不堆叠状态标签。

### 二级页

- 起床时间：时间、重复星期、保存。
- 晨间播报：有序项目列表，每项开关与拖拽把手；城市、音乐说明、日程来源、提醒内容点进子页编辑。
- 设置：主题、声音、权限与设备就绪、重新选方案。
- 权限：通知、闹钟与提醒、锁屏全屏分别说明用途，按需跳转系统；拒绝后仍可浏览/编辑/试听，不循环弹窗。位置暂为手动城市，不索取无意义定位权限。系统日历由用户显式选择连接，只读当天内容；拒绝可切回手动或在播放时跳过。

### 响铃 → 播报

响铃页显示超大当前时间；主动作“长按，我起床了”需持续按住约 0.8 秒，进度即时反馈。抬手提前取消，减少迷糊态误触；TalkBack 用户可以激活标准无障碍动作。贪睡弱化为独立大热区。关掉闹铃立即停止铃声，在同一界面过渡到播放态，不再二次确认“开始播报”。

播报态大字展示正在播放的项目、正文与进度；底部只保留暂停/继续、跳过本条、结束三个 ≥48dp 控件。音乐暂停保留位置；语音暂停保留最近收到的朗读范围，在该范围起点继续，避免把原生 TTS 的停止冒称为精确暂停；引擎不提供范围时从本条开头恢复。

## 兜底与真实能力边界

- 天气仍是明确标注的固定示例，不伪装成联网天气；本地旋律和手动内容无需网络。
- 手动日程/提醒为空、日历未授权/读取失败/当天无事件：跳过该项，保留短提示并继续后续项目。
- 中文语音缺失/初始化超时：说明如何补齐，跳过无法朗读的项目；可用的本地音乐继续播放。完成页保留跳过原因。
- 定位与第三方音乐平台尚未接入，不展示无效的“已连接”状态。音乐是随包附带的原创合成旋律。
- 闹钟精确权限或通知被拒绝：保存偏好但说明尚未启用，不展示虚假的下一次已设置时间。锁屏全屏权限缺失时通知仍是后备入口。
- 暂停/跳过/停止必须同步更新界面与通知；结束、来电或音频焦点丢失时释放播放器、TTS、音频焦点和唤醒锁。
- 设置采用现有偏好迁移，0.2 使用相同包名与签名，可以覆盖安装保留 0.1 的时间和内容。
