# 设计说明

## 玩法定位

让玩家通过选择颜色和摆件，把小卧室布置成自己喜欢的样子，并导出图片分享。当前版本用于确认视觉方向和基础交互，不包含关卡进度或经营系统。

## 房间与视觉

- 约 12 平方米的单人卧室概念，采用开放式立体小屋视角；非精确比例的建筑设计图。
- 包含床、床头柜、台灯、书桌、椅子、窗户、挂画、地毯、绿植和小猫。
- 默认抹茶奶油配色，另外提供蜜桃午后、海盐晴天两套整体风格。
- 图形全部内置在 SVG 中，不依赖外部美术素材或字体。

## 已实现功能

| 操作 | 行为 |
| --- | --- |
| 选择整体风格 | 同时更新墙面、床品和地板颜色 |
| 单独换色 | 墙面、床品、地板分别提供四种配色 |
| 增减摆件 | 切换地毯、绿植、小猫的显示与隐藏 |
| 点击家具 | 显示对应的小物件文案 |
| 恢复初始布置 | 恢复默认配色并显示三个摆件 |
| 保存图片 | 生成 1600 × 1300 PNG 房间图，不包含操作面板 |
| 窄屏显示 | 操作面板排在房间下方 |

## 尚未实现

自由拖动、旋转或缩放家具，多房间或家具库存，关卡、货币与解锁机制，刷新后恢复布置，账号、后端、付费以及平台登录和分享 SDK。

## 后续开发方向

先验证视觉风格及装饰操作，再考虑加入家具自由摆放与布置存档。正式发布前应分别核实小红书与 TapTap 的准入、运行载体和接口要求。
