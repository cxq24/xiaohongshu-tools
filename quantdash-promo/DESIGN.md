# QuantDash · 30 秒推广片 V1

当前模式：按用户“先制作、成片确认后再作为广告使用”的要求，自主制作完整审核样片。不会接入游戏、启用隐藏关视频或发布广告。

## 产品依据

从 QuantDash 官方 GitHub 示例仓库确认：面向开发者和量化研究员，提供 A 股、ETF、港股、美股行情；Python SDK 支持统一 K 线调用、A 股全市场快照、复权参数和 DataFrame 输出。`research/sources.json` 固定参考提交，所有功能文案据此编写。

官网、文档站被当前环境的网络白名单拦截，未获取官网截图、品牌标志或视觉 tokens。V1 因而采用明确的“接口能力动画演示”，不复刻或伪造产品控制台；深蓝／青色是本片暂定视觉方案，不声称是官方品牌规范。QuantDash 采用文字排版，不另造官方 logo。后续可按真实官网校准品牌视觉。

不调用付费／登录 API，不采集账户，不出现真实 API Key、客户数据、收益率、延迟／稳定性承诺或未经核实的免费额度。代码来自公开示例，几何数据流和 K 线仅为示意。

## 视觉与运动

近黑深蓝 `#07121E`、表面 `#0C1E2F`、白 `#F0F6FC`、次级蓝灰 `#94A9BE`，强调青 `#66E2D1`。大标题 84–104px，正文 34–42px，代码 36px；实际数据密度低于控制台，优先手机可读性。所有正文与二维码落在左右 80px、上下 140px 的安全区域。

动效取“专业、清楚、克制”：21 帧左右的主入场，非线性缓动，不逐拍震屏、不堆叠辉光。品牌和核心语句落定至少停留 1 秒；末页网址和二维码留足阅读时间。原创音乐 120 BPM，镜头切点落在 0／4／10／17／23 秒，均为半秒拍点。

## 验收范围

先静态 styleframe，再镜头关键帧，最后成片抽帧、时长／编码／黑帧／音量／二维码识别与独立审查。试听能力不足时只报告音轨分析，不把波形测量称为人工试听。无旁白，不宣称真人配音。


## 已记录的制作取舍与审查修正

Freesound 搜索被当前环境网络策略 403 拦截；本片采用有意设计的原创抽象数据音色与配乐，不声称符合参考项目 A10 的 Freesound 选材流程。没有复用其许可无法核对的历史音源，也未声称人工试听。装饰性英文眉题、步骤号／页码采用小字号，不作为中文功能正文或行动入口；功能正文、代码、文档域名与示意说明已提高可读字号。K 线绘图缩进卡内并裁切；市场运动结束后保持至少一秒。

依据实测的 Remotion 4.0.484／AAC 48k／H264 MP4 管线，源音乐与音效统一提前 2048 samples（约 1.28 帧），用最终解码音频回测净偏移。中央 cue 表记录名义动作时刻，补偿独立记录，不修改拍点口径。
